# Store Screenshots Guide

## Required Dimensions

| Platform | Size | Device |
|----------|------|--------|
| iPhone 6.7" | 1290 x 2796 | iPhone 15 Pro Max |
| iPhone 6.5" | 1284 x 2778 | iPhone 14 Plus |
| Android Phone | 1080 x 1920 | Standard phone |
| Android 7" Tablet | 1200 x 1920 | 7-inch tablet |

## Screenshots to Capture (5 per size)

1. **Face Scan Results** — Results screen showing the photo with landmark overlay, overall potential score, and radar chart breakdown
2. **Daily Tasks** — Home screen with the daily mission list, streak badge, XP bar, and progress indicator
3. **Water Tracker** — Water screen showing the progress ring, quick-add buttons, and weekly bar chart
4. **Progress Dashboard** — Progress screen with Lock In Score, score trends chart, and timeline
5. **Achievement Badges** — Progress screen scrolled to show earned achievement badges

## Tips

- Use a device or simulator matching the exact dimensions above
- Ensure dark mode is active (default)
- Populate the app with realistic data before capturing (several scans, tasks completed, water logged, achievements earned)
- Take screenshots during the animated score counter for visual appeal on the results screen
- For the App Store, the first screenshot is the most important — use the Face Scan Results screen

## File Naming Convention

```
{platform}-{size}-{screen-number}-{screen-name}.png

Examples:
iphone-67-01-scan-results.png
iphone-65-02-daily-tasks.png
android-phone-03-water-tracker.png
android-tablet-04-progress.png
```
